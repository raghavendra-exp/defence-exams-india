## 🎖️ Overview

**DEFENCE EXAMS INDIA** is a state-of-the-art, responsive, bilingual (English + हिंदी) preparation ecosystem built specifically for aspirants targeting recruitment and commissioned officer entries in the **Indian Army, Indian Navy, Indian Air Force, and Indian Coast Guard**.

Rather than offering generic study material, the platform provides dedicated, notification-aligned modules for every examination with authoritative eligibility criteria, official marking schemes, medical and physical standards, and interactive preparation labs.

---

## 🌟 Key Features & Modules

### 1. 🔍 Smart Exam Discovery Engine (Eligibility Finder)
- **Multi-parameter matching**: Evaluates Date of Birth, Gender, Marital Status, 10th/12th Streams (PCM check), Graduation Degree, Engineering Branch, NCC C-Certificate, and Active Service Status.
- **Accurate age calculations**: Computes exact age in years, months, and days against upcoming commission cut-off dates.
- **Direct Official Links**: Points directly to official commission portals (`upsc.gov.in`, `joinindianarmy.nic.in`, `joinindiannavy.gov.in`, `afcat.cdac.in`, `joinindiancoastguard.cdac.in`).

### 2. 📚 Comprehensive Exam Engines
Dedicated syllabi, selection stages, and branch breakdowns for:
- **UPSC NDA & NA**: Army, Navy, Air Force wings, Naval Academy (10+2 Cadet Entry).
- **UPSC CDS**: IMA (Dehradun), INA (Ezhimala), AFA (Dundigal), OTA (Chennai).
- **IAF AFCAT**: Flying Branch, Ground Duty (Technical - AE(L)/AE(M)), Ground Duty (Non-Technical).
- **Agniveer Army**: General Duty (GD), Technical, Clerk / Store Keeper Technical (SKT), Tradesman.
- **Agniveer Navy**: SSR (Senior Secondary Recruit) and MR (Matric Recruit).
- **Agniveer Air Force (Vayu)**: Science Subjects (PCM), Other than Science Subjects, and Combined Streams.
- **Indian Coast Guard (ICG)**: Navik (General Duty), Navik (Domestic Branch), Yantrik (Mechanical/Electrical/Electronics), Assistant Commandant.
- **Defence Technical Entries**: 10+2 TES (Army), 10+2 B.Tech (Navy), TGC (Technical Graduate Course), SSC-Tech, UES, and CDAC.

### 3. 🎯 8,750+ Syllabus-Aligned Question Bank & Practice Engine
- **Categorized by exam and subject**: Mathematics, GAT, English, General Science (Physics, Chemistry, Biology), History, Geography, Polity, Defence GK, Reasoning, and Numerical Ability.
- **Clear origin labels**: Transparently badged as `VERIFIED PYQ`, `PYQ-STYLE`, or `ORIGINAL PRACTICE`.
- **Instant feedback**: Detailed bilingual explanations, shortcut hints, and one-click bookmarking or adding to the Error Notebook.

### 4. ⏱️ Real-Time Mock Test Simulator
- **Exact Official Marking Schemes**:
  - NDA Math: +2.5 marks / -0.83 penalty.
  - NDA GAT & CDS: +4 marks / -1.33 penalty (NDA) or +1 mark / -0.33 penalty (CDS).
  - AFCAT: +3 marks / -1 penalty.
- **Real Exam Environment**: Timed countdowns, question palette (Answered, Marked for Review, Unvisited), and comprehensive post-test score analysis.

### 5. 🏅 SSB & AFSB 5-Day Selection Lab
- **15 Officer Like Qualities (OLQs)**: Detailed breakdown across Factor I (Planning & Organizing), Factor II (Social Adjustment), Factor III (Social Effectiveness), and Factor IV (Dynamic).
- **Interactive WAT Drill**: 60-word flash simulator with real 15-second countdown intervals and candidate response recording.
- **SRT Practical Scenarios**: Real-world situational response test dilemmas with officer-like solution guidelines.
- **OIR & PPDT Guides**: Step-by-step psychological test procedures and screening tips.

### 6. 🏃 Physical Fitness (PFT) & Medical Standards Center
- **Entry-Wise Physical Standards**: 1.6 km run timing benchmarks (e.g. Group I vs Group II for Agniveer), beam pull-ups, push-ups, and 9-foot ditch jump criteria.
- **Height-Weight Matrix**: Officially notified height and weight charts by age group.
- **Vision Standards**: Uncorrected and corrected visual acuity standards (6/6, 6/9, CP-I, CP-II, CP-III) and LASIK/PRK guidelines.
- **Medical Appeal Workflow**: Interactive walkthrough of Temporary Unfit (TU) and Permanent Unfit (PU) appeal procedures with 21-day and 42-day Review Medical Board (RMB) timelines.

### 7. 🛡️ Defence GK & Strategic Studies Lab
- **Tri-Service Equivalent Rank Structure**: Army, Navy, and Air Force ranks from Sepoy/Aircraftman to Field Marshal/Marshal of the IAF.
- **Operational Commands**: Interactive directory of 7 Army Commands, 3 Naval Commands, 7 Air Force Commands, and Tri-Service Commands (ANC & SFC).
- **Historic Military Operations**: Operation Meghdoot (Siachen 1984), Operation Vijay (Kargil 1999), Operation Trident (1971), Operation Cactus (Maldives 1988), and Operation Kaveri (Sudan 2023).
- **Joint Military Exercises**: Yudh Abhyas, Garuda, Varuna, Mitra Shakti, Indra, Surya Kiran, and Malabar.

### 8. ⚡ Speed Lab, Formula Book & Learning Accelerators
- **Speed & Shortcut Lab**: Mental math tricks, digital sum verification, Vedic math shortcuts, and grammar rule checklists.
- **Formula Master**: Quick-reference formulas for Algebra, Calculus, Trigonometry, Mechanics, Optics, and Modern Physics.
- **Spaced Flashcards**: Interactive flip-cards with Leitner-inspired mastery tracking.
- **Error Notebook**: Dedicated tracking for silly mistakes, conceptual gaps, and time-management issues.

### 9. 🗺️ Zero-to-Defence Roadmap & Study Planner
- **12-Level Structured Roadmap**: From eligibility exploration, NCERT foundation building, to final SSB recommendation and merit list tracking.
- **Interactive Daily Planner**: Set target exams and study hours with progress persistence in browser storage.

### 10. 🎖️ Special Entry Modules
- **NCC Special Entry**: Direct SSB privileges, C-Certificate grading rules (Alpha/Bravo), and exemption from written examinations for Army NCC Special Entry.
- **Ex-Servicemen (ESM) Reservation**: Age relaxation calculator (service period + 3 years) and reservation quotas across civilian and defence recruitment.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or 20 recommended)
- `npm`

### Installation
```bash
# Clone the repository
git clone https://github.com/ragha-exp/defence-exams-india.git

# Navigate into project directory
cd defence-exams-india

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production
```bash
npm run build
```
This compiles TypeScript types (`tsc -b`) and generates the optimized production bundle in `./dist`.

## 🚢 Deploying to GitHub Pages

This repository includes an automated GitHub Actions workflow at `.github/workflows/deploy.yml`.

1. Go to your repository settings on GitHub: `Settings > Pages`.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push any commit to the `main` branch:
   ```bash
   git push origin main
   ```
4. The workflow will automatically build the project and publish it to `https://<your-username>.github.io/defence-exams-india/`.
